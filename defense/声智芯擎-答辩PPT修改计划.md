# 《声智芯擎》答辩 PPT 修改计划

以 `声智芯擎-答辩-AMD风格.pptx` 的 25 页为底稿，页号按 PowerPoint 顺序。两份文档重叠处按《人话版》执行。保留现有蓝白配色、顶部章节导航和底栏，在本地副本上修改。正文留结论和支撑数据，型号、测试用例名和执行细节按答辩需要放到讲稿或备答。

## 指定页面

### 第 4 页　下方拓展流程图

- 把左下现在的四个等大黄框、交叉箭头和「已完成并有报告」图例，改成一条设计主干和两个并列验证出口。左上基础 FFN1 流程和右侧六项指标继续使用原版布局。
- 主干采用横排「完整 FFN ＋ 单头注意力」接「十二层 PostNorm 编码器」。从编码器向下分出「40 nm ASIC 综合」和「Z100 FPGA 上板」两条支路。两条线各自落到一个可讲的结果，ASIC 支路保留新增面积 **1.489 mm²** 和整机功耗 **100.6 mW**，FPGA 支路写 **120 条预测与定点参考一致**。
- 删除最底部的小字。计时起止点、12 组平均吞吐和第 4 层功耗的口径放在讲稿与对应指标页。右栏频率卡写「150 MHz 综合约束」，其下单列 `Setup WNS 0.00 ns` 与 `SS Hold WNS −0.17 ns`。

### 第 5 页　四项优化总览

- 删除整条黄色总结框，四列等宽铺开，把空间留给数据和说明。顶部改成「共享 SRAM 每拍传 1 个 32 位字，片内分 bank 和广播每拍向阵列供 32 个 INT16 操作数」。这句话交代两个存储层级各自承担的流量。
- 第四列标题改「定点写回与中断等待」。下面排三条同字号左对齐短句，分别讲「舍入、饱和后，两项 INT16 打包写回」「DMA 保留两笔在途事务」「E203 执行 WFI，末笔写响应后由 IRQ 唤醒」。能耗卡只留 **8.356 → 7.980 µJ／任务** 和 **降低 4.50%**，小注标「同一任务 RTL-SAIF 对照」。
- 第三列把「片内读／MAC」写成「每次乘加的片内读取」，数值保留 `2.00 → 0.25 次`。第二列把「无宏冲突」收窄为「阵列读访问分散到 32 个宏」，与差分恢复仍可能触发 `x_conflict` 的说明一致。

### 第 6 页　左侧换任务数据流动图

- 使用已有 `ffn1-task-dataflow.gif`。文件是 **5 帧原生 GIF**，画面依次突出 Host 装载、E203 配置、DMA 装载、阵列计算与写回、末笔响应与 IRQ。按比例放在左侧，照顾 1159×496 的宽画幅，留一行图注「实线表示数据，虚线表示控制与中断」。
- 右侧推进条件与动图顺序一致。面积统计边界移到第 17 页，腾出空间让 `首块装载`、`计算/预装/写回`、`末笔响应` 三个条件可以在投影上读清。完成判定直接写「末笔写响应返回后置 `done`，触发 IRQ」。
- 编辑阶段用 PowerPoint 放映确认 GIF 自动播放、循环和反复切回后的表现。已有首帧可用于静态 PDF。

### 第 10 页　右侧两块改成示意图

- **上半块画 SRAM 同拍读写。** 左边三条短路标表示「阵列读 X 当前组」「DMA 写 X 空闲组」「W 常驻宏供数」。右边只画一个 `x_conflict` 例外小图，展示差分恢复读前驱行与写入命中同一宏时，暂停接收 1 拍。左侧原有 52 宏结构图和规格表保留。
- **下半块画尾块优先。** 用三块编号示意 `12 → 1 → 0 → …`。块 12 注「96–98 行」，块 1 注「8–15 行」，A/B 着色显示缓冲交替。图下保留「按真实行号写回」及 `index = row × 128 + column_pair`。完整执行序列和异或表达式移到备答。

### 第 11 页　移除底部黄色说明框

- 右上主数字保留 **0.022189%**，下方两行写「12 层中最大汇总 NRMSE」「9,982 条本地样本，赛题门槛 3%」。删掉「裕量约 135 倍」和关于未来评测流程的叙述。
- 中间用清晰的写回顺序图标出「INT40 累加值 → 除以 $2^{15}$ 并取最近偶数 → 饱和为 INT16 → 两项组一字」。左侧把 `2.5 → 2`、`3.5 → 4` 排在同一行。饱和边界示例进讲稿，写成「舍入得到 32,768 时，输出限幅为 32,767」。
- 本页讲解码输出相对浮点参考的误差，第 15 页讲 RTL 与整数模型的逐位核对。保留这两个验证对象的具体名称。

### 第 12 页　用周期对比替换主讲 Roofline

- 顶部保留整任务时间条，三段直接标 **9,588 拍 Host 装载与 E203 启动**、**6,793 拍 DMA LOAD**、**15,623 拍 RUN**。在 RUN 段下方缩进一条 **13,312 拍阵列有效归约**。剩余部分标「RUN 内其余周期」，详细计数放左下小表，注明其中结果队列等待 **2,259.17 拍**。
- 右下画同一横轴、从零开始的两条横条，比较**共享 SRAM 有效载荷下界 30,835 拍**与**RTL 实测均值 32,006.83 拍**。下界条按 Host 写入 **9,081.5**、DMA 读入 **9,081.5**、DMA 写回 **12,672** 分段。两条末端用差值标记 **约 1,172 拍（实测比下界高 3.8%）**。图注标「单端口共享 SRAM 按每拍一个 32 位字估算」。
- 保留一句讲稿「装载与启动占 51.2%，RUN 中阵列有效归约占 85.2%。」原图的 **18.6 MAC/B** 只含 DMA 读写，整任务还含 Host 装载。如备答保留 Roofline，整任务点按 **30,835 字**计算为 **13.15 MAC/B**，并注明 **4,865 任务/s** 是共享端口有效载荷上限。备答 B 一并更新。

### 第 15 页　按参考图重排分层验证工具链

用参考图的「左侧统一输入、右侧三条横向泳道」组织信息，沿用本 PPT 的字体、标题和底栏。左侧放冻结 RTL、12 组 X/W/b、E203 固件。固件旁标 GCC 编译，避免表现成 GCC 生成测试向量。右侧每条泳道最右放一项可核对的证据。

| 泳道 | 页面中间 | 右端结果 |
| --- | --- | --- |
| 静态质量与低功耗检查 | Slang 前端检查。SpyGlass Lint 和 Power 可并列显示，以对应配置的报告为准 | 规则与门控分析报告，有对应记录时展示摘要 |
| 动态功能与覆盖率 | Icarus 定向测试、真实 E203 固件的 SoC 回归。独立列出 VCS/Verdi 波形、VCS Coverage/URG，标清相应配置 | 每任务复位和连续运行各完成 12 层。覆盖率图可用备答页展示，并注明采集配置 |
| 逐位一致性与数值精度 | 上支路用整数模型生成 ACC40/Y16 参考值，与 RTL 比对。下支路将整数输出解码后与浮点 FFN1 比较 | 每模式 ACC40 **304,128** 项、Y16 **304,128** 项，**0 失配**。最大逐层 NRMSE **0.022189%** |

只展示与对应 RTL 版本绑定的静态报告和覆盖率。SpyGlass 或覆盖率若来自 E203 总线验证版，给该证据加版本标签，避免归到 Q128 提交配置。参考图里的「原始报告待补」删掉。原页详细测试平台表转备答或讲稿。《人话版》所附覆盖率、功耗层次、面积、时序和回归截图作为核对材料，只有测试配置与页面指标对应时才作为该页证据。

### 第 17 页　左侧用面积拆分填实，右侧删选层说明

- 左半上方用一条整机组成条展示 **2.738 mm²**，分为新增设计、E203/TCM 和共享 SRAM。下方把新增设计放大，画 **0.243 mm² SRAM** ＋ **0.263 mm² 逻辑与接口**，旁边用一条短刻度标出 **0.506 / 2.25 mm²（22.47%）**。去掉「新增逻辑本身很小」，面积数字直接承担结论。
- 右侧保留模块功耗、**37.346 mW** 和 **7.60 µJ／任务**。功耗分布条标加速器 **77.1%**、共享 SRAM **19.9%**、E203 **2.7%**。标题写「第 4 层完整任务 RTL-SAIF」，删除底部的「选层说明」。能量标签写「平均功耗 × 203.603 µs」，小数精度统一到主讲可读的位数。

### 第 18 页　用可编辑公式解释非线性算子

右半去掉大块浅蓝说明底和两张难读的小流程截图，换成三条等宽的公式行。公式用 PowerPoint 原生公式，旁边各放一小段实现图。左半保留拓展 SoC 图和按模块分工的表。标题可简化为「十二层 PostNorm 编码器」。

| 算子 | 公式与配图 |
| --- | --- |
| Softmax | $\Delta_i=\max_j s_j-s_i$，$p_i=e^{-\Delta_i}/\sum_j e^{-\Delta_j}$。小图画取行最大值、指数表和行归一化，标记 $\Delta_i\ge16$ 时指数项置零。讲稿再解释 $\Delta_i\log_2e=I+F$ 与 257 项 Q24 表。 |
| LayerNorm | $y_i=\gamma_i(x_i-\mu)/\sqrt{\sigma^2+\epsilon}+\beta_i$。小图画 64 通道累加、整数平方根和定点倒数。保留量化倒数 $\lfloor2^{36}/\mathrm{std}\rfloor$ 到讲稿。 |
| GELU | $\mathrm{GELU}(x)=\max(x,0)-c(|x|)$，$c(a)=a\Phi(-a)$。旁边画修正量曲线并标 `[0,8]` 查表区间、步长 `1/32`。 |

注意力 `QK` 右移 19 位放回左侧注意力模块旁，说明它合并了 Q32 转 Q16 与除以 $\sqrt{64}$。三行正文各自只保留一个公式入口和一条硬件取舍。

### 第 19 页　下方改成能直接讲的两句话

- 左下「驻留有效位随任务生命周期管理」换成「前 11 层的 LN2 结果留在片内，下一层直接读取。最后一层写回共享 SRAM。每条新语音从自己的输入开始。」中止和复位清理放到讲稿。
- 右下两张卡的文案写「4,445 条记录的定点与浮点预测逐条一致，Top-1 均为 97.89%」及「第 11 层汇总 NRMSE 最高，为 0.171%」。饱和计数留在备答。
- 左表保留「层间驻留」「LN1 直传」各自的字数和周期对照。将 **13,855,994 → 4,206,337 拍**单列为「整版迭代」，右侧 **35.66 任务/s** 旁标 `150 MHz 折算`。讲稿避免把不同基线的收益念成连续叠加。
