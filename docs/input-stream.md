# LN1→FFN 输入直传与权重预装载（编码器第五版）

基于 `b71631230c868b6f1f8e8d3e1a9afdb986280512`，保留原 SRAM 输入交接路径，通过运行时配置启用输入直传。先完成单层对照与协议验证，再进入十二层验证；结果及文件指纹由 `collect_input_study.py` 生成到 [机器报告](evidence/input-stream-validation.json)。本轮只评估前端 RTL。

## 数据通路和启动条件

```text
                共享 SRAM 中的 W1/b1/W2/b2
                          │ 双在途 DMA，避开编码器读装载窗口
                          ▼
LN1 原有 RNE / clip16 → 4×32 bit 输入 FIFO → 既有 X 单端口存储体
                                               │ 8 行完整块就绪
                                               ▼
                                       L1 → GELU → L2（复用同一16路 MAC）
                                               │
                                     既有 4×40 bit 输出 FIFO
                                               ▼
                                    原残差相加 → LN2 → 下一层
```

LN1 算术仍先完成整层，再由原打包预读逻辑发送数据；本版没有把 LN1 的逐行计算与 FFN 重叠。

每层仍为 99×64 个 int16，两个相邻元素组成一个32位字，共 3,168 字。W1/b1/W2/b2 共 16,704 字，全部有效后才接收输入；首块 8 行、256 字接收完成后启动。后续 11 个完整块加最后 3 行的边界由累计元素数判定，进入下一块前通过 `WAIT_X` 屏障。最后一块仅需 96 字，不能按完整块等待。

输入复用原有 X SRAM，不增加读写端口：L1 的 PRIME、MAC、下一组预读拥有读端口；输入写入只能使用空闲拍。L2 使用独立中间 SRAM，因此可同时写入后续 X。尤其在 L2 输出被堵住时仍须接收后续输入，否则“LN1 未结束，CPU 尚未启动尾段，FFN 输出 FIFO 已满”会形成互相等待。逐拍断言检查不存在 X 读写冲突和未加载数据读取。

`preload_permit` 在编码器 DMA 读装载阶段拉低，只禁止**新**权重请求；已经发出的请求和两笔在途响应继续排空。共享 SRAM 及其公平仲裁器保持原结构。最初不避让读窗口的实验仅节省 5,140 拍；避让后单层节省 19,518 拍。没有新增乘法器，输入 FIFO 新增 16 B 数据寄存器及少量控制；原结果 FIFO 为 20 B，SRAM 组织不变。

## 配置与兼容

| 配置 | SRAM 输入对照 | 输入直传 |
| --- | --- | --- |
| ENC1 `0x34` | bit3=1、bit4=0 | bit3=1、bit4=1 |
| KWT5 `0x38` | mode=3 | mode=4 |
| 启动顺序 | 编码器前段完成 → 启动 FFN → 启动尾段 | 先启动 FFN 预装载 → 启动前段 → 前段结束后启动尾段 |
| 输入来源 | 共享 SRAM 的 packed int16 | 32位 ready/valid 输入 FIFO |
| 结果去向 | 40位结果 FIFO | 同左 |

bit4 必须与 bit3 配合，bit2 与 bit3 继续互斥。`STREAM_ENABLE=0` 的旧总线不接受 mode4。原 mode0/1/2/3 保留。KWT5 新增只读 `0x98`，记录本次成功接收的32位输入字数；`0x94` 继续记录40位输出结果数。mode4 的 `0x44` LOAD 阶段计数还包含等待首块输入的时间，不是纯总线传输耗时；总线流量以实际握手计数为准。地址合法性约束保持，因此未使用的 X/Y 共享地址仍须合法配置。

前段 DONE 表示全部 3,168 字已经交给输入 FIFO，并不表示全部进入 FFN SRAM；尾段随后并发消费 FFN 输出。禁止先等 FFN 完成才启动尾段。驱动已按此顺序实现，调用者仍使用 `kwt_encoder_layer()`。

取消时停止新输入、清空两个 FIFO，排空已发出的总线事务，清除核内输入/权重有效计数及编码器驻留有效位，再允许新任务。取消会使跨层驻留结果失效，应从新任务的 layer 0 重新装载输入；没有承诺从被取消的中间层续算。专门覆盖了前段已空闲、仍有输入留在 FIFO 时取消前段的情况；取消信号仍会传播给 FFN。输入计数等统计值可保留到下一次启动，不能作为取消后的数据有效位。

## 单层同条件对照

两种模式使用同一 RTL 可执行文件、同一新固件、task 0 的同一冻结输入/权重。主机周期包含输入/参数加载、CPU 调度、硬件计算、最终写回和轮询观察；只执行 layer 0，并写回其最终 6,336 个结果。

| 指标 | SRAM 输入 | 输入直传 | 变化 |
| --- | ---: | ---: | ---: |
| 完整单层任务周期 | 1,250,753 | 1,231,235 | −19,518，−1.5605% |
| 编码器前段周期 | 837,792 | 844,923 | +7,131 |
| 编码器尾段周期 | 251,933 | 225,100 | −26,833 |
| FFN 命令跨度（含预装载等待） | 225,339 | 1,043,766 | 与前段重叠，不能相加 |
| FFN 核活动区间周期 | 209,827 | 209,857 | +30 |
| 编码器 DMA 读32位字 | 23,040 | 23,040 | 0 |
| 编码器 DMA 写32位字 | 9,504 | 6,336 | −3,168 |
| FFN DMA 读32位字 | 19,872 | 16,704 | −3,168 |
| FFN DMA 写32位字 | 0 | 0 | 0 |
| 合计 DMA 字数 | 52,416 | 46,080 | −6,336，−12.0879% |

收益来自搬运减少、预装载及启动重叠，并非 MAC 数量增加或算术拍减少。输入直传令前段等待 X 端口，前段自身变长；整机仍更快。FFN 命令计数从预装载开始，直传时会覆盖大部分注意力计算，不能把其命令周期与前段/尾段相加，也不能据此认为 FFN 算术变慢。轮询相位使各硬件区间之和与主机完整任务差值不完全相同。

输入 FIFO 在单层中传输 3,168 字，生产端满等待 8,190 拍，消费端空等待 1 拍，最大占用 4/4；2,629 次 X 写入发生在 L2 阶段。空等待仅统计 LN1 首次 valid 至全部输入消费之间，排除此前等待注意力的时间。`WAIT_X` 总计 12 拍属于块切换屏障，正常数据并未长时间缺块；慢输入压力测试另覆盖了实际缺块等待。

## 十二层同条件对照

单层收益与 Verilator/Icarus 协议检查通过后，复用同一个可执行文件扩展到十二层。task 0 是两种模式严格匹配的对照；候选另外覆盖其余11条输入，12条输入全部通过且周期均为14,315,119；共144层的 LN1 输入和 FFN 输出逐位一致，编码器饱和计数均为0。中间层 LN2 驻留复用，最后一层写回 6,336 个整数结果。

| 指标 | SRAM 输入 | 输入直传 | 减少 |
| --- | ---: | ---: | ---: |
| 完整十二层任务周期 | 14,549,345 | **14,315,119** | **234,226，1.6099%** |
| 编码器 DMA 读32位字 | 206,784 | 206,784 | 0 |
| 编码器 DMA 写32位字 | 44,352 | 6,336 | 38,016 |
| FFN DMA 读32位字 | 238,464 | 200,448 | 38,016 |
| FFN DMA 写32位字 | 0 | 0 | 0 |
| 加速器 DMA 合计32位字 | 489,600 | **413,568** | **76,032，15.5294%** |

这里的流量是两个加速器对共享 SRAM 的实际 DMA 请求，不含主机装载、CPU 指令取指与软件访问；完整共享 SRAM 观察计数另存机器报告的 `memory` 字段。单层表是执行 layer 0 后立即写回，因此不能简单乘12来代替驻留模式的整机周期。

两种独立模式分别12个任务仍为 **167,134 / 305,708 周期**，与 `b716312` 一致。输入开关关闭后的完整十二层周期也与第四版历史值一致。当前收益成立，因此十二层支持已保留；默认仍显式选择 SRAM 输入，便于随时重做对照。

## 验证与可复现记录

- `tb_ffn_input`：3组全范围数值向量，延迟权重、慢输入、输出等待全部输入后才放行、单端口冲突及就绪断言；两笔在途 abort/error 排空；权重阶段、首块第255字、后续块及输出堵塞时取消并恢复。
- `tb_encoder +input_stream=1`：原注意力/残差/LN1 中间结果逐位核对，输入 packed int16 逐字核对；周期性背压；第3,168字持续受阻时取消并从头重启；尾段结果核对。
- `tb_input_link`：真实编码器、FFN、两个 FIFO、DMA 仲裁和单端口共享 SRAM；取消分别从两端发起，覆盖前段 DONE 但 FIFO 尚未排空；恢复后核对全部输入、FFN 输出和最终结果。
- 两种独立模式分别12个任务；严格 lint、旧编码器异常/仲裁回归。Verilator 与 Icarus 四态日志均需通过，十二层脚本才解除验证门槛。

本轮不重新训练或调整数值格式；6个冻结格式/数学文件的哈希继续与第四版报告一致。4,445条软件 validation 评估沿用此前冻结格式结果，不冒充本轮 RTL 覆盖。
